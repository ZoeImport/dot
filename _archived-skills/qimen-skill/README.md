# qimen-skill（归档）

修复版 `rija-v2` 将历法、排盘、规则解释分开。仍留在归档目录，不会默认安装。

## 使用

```bash
cd _archived-skills/qimen-skill
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q
```

```python
from engine.utils import calculate, format_rija_text, board_to_dict

board = calculate("2026-10-02T08:00:00+08:00", "日家")
print(format_rija_text(board))
print(board_to_dict(board))
```

Python 3.9+，默认北京时间，民用 00:00 换日。可传带时区的 ISO 时间。
日家按夏至/冬至的北京时间日期切换阴阳遁，一天一张盘；时柱仅为附加时段信息。
详见 [SKILL.md](./SKILL.md) 的流派约定与每日报告协议。

## 修复内容

- 日干支基准改为 2000-01-01 戊午；修正月份节气排序、跨年和时区边界。
- 节气采用固定版本 `lunar-python==1.4.8`，保留 UTC `ephem.Date` 接口。
- 日家增加阴遁休门起宫和阴遁太乙旬首表，太乙按旬内日数逐日飞宫。
- 八门按实际八方转动，九星按宫号顺逆飞，避免混淆。
- 修正喜神与十二黑黄道；输出旬首、旬内日数、太乙宫和贵人/空亡冲突。
- 时家增加独立规则层：旬空、驿马、五不遇时、击刑、三奇入墓、门宫关系、门星伏吟/反吟、有名格子集。
- 结构化规则证据、宫内备注、全盘备注均保留在 JSON 中。

## 校验与限制

2026-10-02 08:00 为丙午年、丁酉月、己酉日、戊辰时：阴遁，休门坎1，甲辰旬第六日，太乙坤2，喜神东北，贵人子申，截路空亡申酉，辰时天刑。
完整九宫见 [示例](./examples/usage_examples.md)。

测试覆盖阴阳遁完整六十甲子、三日锚点、每日九星移动、全部黑黄道起点、交节/换日/时区边界、参数文件一致性、规则正反例及历法跨世纪抽样。
历法抽样与 `lunar-python` 比对；节气本身也来自该库，因此这不是第二个独立天文算法验证。
日家传统规则依据用户提供的审计与盘例实现，尚未逐条完成古籍原文的独立文献核验。

**时家仍为实验性实现**，JSON 明确返回 `status="experimental"`：
九星转盘/天禽寄宫和完整置闰尚未实现并验证。新增标记依赖输入盘面，不会使旧盘面自动变得可靠。
完整有名格、旺衰、用神路由、应期也尚未实现。

每日输出应当是“盘面事实 → 真实任务 → 象意映射 → 独立现实判断 → 1–3 个行动”，保留冲突，避免绝对吉凶结论。
本仓库修复不修改外部定时任务、邮件监控或日历配置。
