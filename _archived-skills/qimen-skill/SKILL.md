# 奇门排盘与行动复盘

本 Skill 保留在 `_archived-skills/`，不会随默认安装复制到技能目录。
修复后的日家规则版本为 `rija-v2`。时家仍为实验性实现，不能称为已经完成的可靠解盘器。

## 三层边界

1. **历法**：`engine/calendar_core.py` 计算四柱、节气、旬首、符头。
2. **排盘**：`rija_board.py` 输出日家八门九星；`shijia_board.py` 输出实验性时家盘。
3. **规则与解释**：`analysis_rules.py` 识别可核验标记；模型依据明确的问事和现实材料解释，不能把象意当成事实或成功概率。

不要手写一个看起来合理的盘，必须运行代码并保留盘面校验结果。
不要因为单个吉门、吉星或贵人就得出绝对结论；冲突信号必须同时呈现。

## 时间约定

- 默认时区 `Asia/Shanghai`；无时区输入视为北京时间，有时区输入先转换为北京时间。
- 日干支采用民用 **00:00 换日**，不采用 23:00 子初换日，不校正真太阳时。
- `datetime` 历法调用按节气精确时刻换年、换月；`date` 调用按节气所在北京时间日期换年、换月。
- **日家阴阳遁按节气所在民用日期切换**：夏至当日阴遁，冬至当日阳遁。这是本版本为“一天一张日盘”采用的明确约定；临界日若使用按交节时刻切换的流派会不同。
- 日家的运行时柱、黑黄道时段只是附加信息。改变运行小时不会重新布日家八门九星。
- 日干支基准：2000-01-01 **戊午**（六十甲子索引 54），2026-10-02 **己酉**。
- 节气使用固定版本 `lunar-python==1.4.8` 的寿星历表，转为 UTC `ephem.Date` 保持旧接口；不再依赖旧太阳黄经近似算法。

## 日家规则

### 休门与八门

四仲日为三日一宫锚点，其他日向前回溯最近的子、卯、午、酉日。
阳遁起宫表：

| 四仲日 | 休门 |
|---|---|
| 甲子、戊子、壬子 | 坎1 |
| 丁卯、辛卯、乙卯 | 坤2 |
| 庚午、甲午、戊午 | 震3 |
| 癸酉、丁酉、辛酉 | 巽4 |
| 丙子、庚子 | 乾6 |
| 己卯、癸卯 | 兑7 |
| 丙午、壬午 | 艮8 |
| 乙酉、己酉 | 离9 |

阴遁用对宫表（宫号 `10 - 阳遁宫号`），不是复用阳遁表。
八门序：休、生、伤、杜、景、死、惊、开。
阳日干顺时针，阴日干逆时针，**取决于日干，不取决于阴阳遁**。
八方顺时针为 `1→8→3→4→9→2→7→6→1`，不经过中5。
“三日一宫”指休门起宫；其他门仍受每天日干阴阳影响。

### 太乙与九星

| 旬首 | 阳遁太乙起宫 | 阴遁太乙起宫 |
|---|---|---|
| 甲子 | 8 | 2 |
| 甲戌 | 9 | 1 |
| 甲申 | 1 | 9 |
| 甲午 | 2 | 8 |
| 甲辰 | 3 | 7 |
| 甲寅 | 4 | 6 |

太乙从旬首起宫按**旬内日偏移**逐日飞宫：阳遁宫号顺飞，阴遁宫号逆飞，包含中5。
例如阴遁甲辰旬：甲辰7、乙巳6、丙午5、丁未4、戊申3、己酉2。
布九星时从当天太乙宫开始，星序为：太乙、摄提、轩辕、招摇、天符、青龙、咸池、太阴、天乙；阳遁宫号递增、阴遁递减，九宫各一星。

### 附加规则

- 喜神：甲己艮、乙庚乾、丙辛坤、丁壬离、戊癸巽。
- 天乙贵人：甲戊庚丑未、乙己子申、丙丁亥酉、辛寅午、壬癸卯巳（本版本口诀）。
- 截路空亡：甲己申酉、乙庚午未、丙辛辰巳、丁壬寅卯、戊癸子丑。
- 时段青龙起点：子午日申时、丑未日戌时、寅申日子时、卯酉日寅时、辰戌日辰时、巳亥日午时。
- 黑黄道输出按子到亥索引：青龙、明堂、天刑、朱雀、金匮、天德、白虎、玉堂、天牢、玄武、司命、勾陈依次从青龙起点顺排。
- `conflicts` 保留贵人与截路空亡的交集，不抵消、不隐藏。

古籍版本与流派可能存在差异。本版本规则依据本次用户提供的审计盘例及所述传统口诀固定下来；未将未核对的古籍引文标成已核验依据，也不对日家星曜机械给出统一吉凶评分。

## 时家当前状态

输出 `status="experimental"` 与中文限制说明。
现有九星天盘仍混合飞布逻辑，**未完成标准转盘的天禽寄宫与携带中宫干实现**；置闰也仍是局部符头比较，未实现跨节气的完整置闰历序。不得用于可靠的自动决策，也不得因测试通过就宣称这两项已修复。

已修复外八宫顺时针顺序、拆补以符头定元、跨年节气起日。
新增的规则层对给定盘面输出 `markers`（rule、gong、evidence）、宫内 `notes` 和全盘 `patterns`：

- 时旬空亡和时支驿马（明确采用时支而非日支）。
- 五不遇时：时干克日干，且天干阴阳同类。
- 六仪击刑：戊震3、己坤2、庚艮8、辛离9、壬癸巽4。
- 三奇入墓：采用阴阳干顺逆墓库，乙坤2、丙乾6、丁艮8；其他流派需另建版本。
- 门迫（门克宫）与宫克门。
- 门/星分别检测全盘伏吟、反吟，不由单宫推断全盘。
- 天地干有名格子集：戊加丙青龙返首、丙加戊飞鸟跌穴、辛加乙白虎猖狂、乙加辛青龙逃走。

尚未实现：完整有名格库、旺衰、问事用神路由、应期。标记的正确性不代表其输入盘已经通过传统排盘验证。

## 安装、调用与验证

Python 3.9+（需要 `zoneinfo` 及系统时区数据库）。

```bash
cd _archived-skills/qimen-skill
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q
```

```python
from engine.utils import calculate, board_to_dict, format_rija_text

board = calculate("2026-10-02T08:00:00+08:00", "日家")
print(format_rija_text(board))
data = board_to_dict(board)
# data 包含九宫、四柱、时区、规则版本、旬首、旬内日数、太乙宫与冲突信号。
```

参数数据 `data/rija_params.json` 与代码映射有一致性测试。
回归包括 2026-10-02 全九宫、阴阳遁全六十甲子、三日锚点、逐日九星、黑黄道、时区/换日/交节边界，以及 1900–2100 每十年每月的历法抽样。

## 每日自动报告协议

一天只起一张日盘，以当地日期与规则版本为键，不在看到结果后换小时重起日盘。

1. 盘面事实：日期、时区、四柱、阴阳遁、旬首与旬内日数、太乙、完整九宫及校验结果；附运行时柱与黑黄道。
2. 实际事项：只使用当前上下文或已授权工具中今天及最近约七天明确的任务、安排；没有信息就说明，不虚构最近会话或日历。
3. 逐项映射：说明采用哪个门、星、方位作为反思提示，保留冲突与版本差异。
4. 现实判断：优先依据源码、证据、截止日期、风险、资源和事实核查，给出即使没有奇门也成立的理由。
5. 只选一至三个主动作，可在晚上按实际结果复盘。

不得从象意推出必须购买、投资、就医/停药或自动发送邮件等动作。
本 Skill 不配置自动任务，不访问邮件或日历；这些连接、授权及任务配置属于外部系统。
